## Notes
**`upper_*` input fields (3) and readers**
- `upper_row: BoundaryRow`: read only by non-atmospheric trials (solve_trial) and validate. Atmospheric ignores it (replaced by `top_row`) but validate still checks it (the "ignored row" check) -> Head, Flux.
- `upper_condition: BoundaryCondition`: non-atmospheric trial and validate (Head/Flux); atmospheric reads only a Dirichlet value as `hCritA`; `prescribed_head` residual exclusion keys on Dirichlet (both atmospheric and Head today).
- `upper_boundary_flux: f64`: `validate_finite`, and `balance` only when not atmospheric (atmospheric uses its computed exchange). So it is read by Head and Flux only; the atmospheric callers pass 0.0 unread. Same shape as 19.4.2 `lower_boundary_flux`.

**Proposed definition** (`water_solver.rs`, next to `WaterStepInput`; `UpperBoundaryMode` in atmospheric.rs is the unrelated flux/head switch state, so no name clash):
```rust
#[derive(Clone, Copy, Debug, PartialEq)]
pub enum UpperBoundary {
    /// Prescribe top-node head; `row` is the caller-supplied upper row, `flux` the measured signed exchange into the domain.
    Head { head: f64, row: BoundaryRow, flux: f64 },
    /// Prescribe signed flux into the domain; `row` as above. `flux` feeds both the Neumann value and the balance.
    Flux { flux: f64, row: BoundaryRow },
    /// Atmospheric switch; row and exchange are derived each trial.
    Atmospheric { critical_head: f64 },
}
```
Condition derived: Head -> `Dirichlet{value: head}`, Flux -> `Neumann{flux}`.

**Atmospheric consumption**: `advance_atmospheric_step` requires `Atmospheric{critical_head}`; `prepare_step` and `decide_transition` read it directly (one `match`/accessor, no Dirichlet extraction). `plan.condition` for ponded head is still `Dirichlet{critical_head}` (unchanged arithmetic).

**Error-variant check**: `UnsupportedAtmosphericInput` has exactly one producer, `critical_head()` (atmospheric.rs:221). That producer disappears. Consumers: error.rs:110/:184, tests atmospheric.rs:~474, water_acceptance.rs:~253, in-crate test at atmospheric.rs:~491. Removed only if Q1 is answered "no new check".
