### Cross-site comparison (register rule)

| Site | Rule | Matches `c1=c2`? |
|---|---|---|
| `:780-792` Level 1 bottom (`F1`, `F(1)=F1+alf*cBot*vO(1)` for `kBotCh=-1`) | natural flux row (dispersive plus advective) | no |
| `:811-814` Level 2 bottom, `kBotCh=-1`, `vN(1)>0` | natural `D1/E1` row with `F2` | no |
| `:816-818` Level 2 bottom, `kBotCh=-1`, `vN(1)<=0` | `c1=c2` | yes (the reached branch) |
| `:823-827` Level 2 bottom, `kBotCh=0` | `c1=c2` (free drainage) | yes |
| `:868-893` Level 1 top (`FN`, `F(N)=FN`) | natural flux row | no |

Result: the same zero-flux total-flux code (`kBotCh=-1`) takes the natural row when `vN(1)>0` and the `c1=c2` row when `vN(1)<=0`.
