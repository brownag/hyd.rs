## Notes
- The dependency harness stages a hash-verified immutable source copy, applies `0001-gfortran-portability.patch`, then emits `staging-manifest.json` and `build-manifest.json` under `.development/reference-build/`; the runner must consume rather than replace that provenance.
- `HYDRUS.FOR:111-140` reads `LEVEL_01.DIR` when no usable data-path argument is supplied and constructs backslash-suffixed `Selector.in` and `Profile.dat` paths. The runner must account for the GNU portability behavior and use its own copied input directory.
- `BasInf` reads file version, feature flags, material/boundary configuration; `NodInf` reads header-count, node/species dimensions, then nodes; `TmIn` reads timestep and print-time records. A no-chemistry, no-temperature, water-only deck minimizes conditional records; `ATMOSPH.IN` is nevertheless committed because the task scope requires it.
- Validation policy requires one temporary output directory per run, immutable copies, explicit timeout, stdout/stderr capture, exit/completion evidence, inventory, output hashes, and malformed/truncated-record rejection.
- The smoke deck is only a bootstrap execution probe. It cannot become a fixture, baseline, parity result, tolerance, numerical validation, or release claim.
