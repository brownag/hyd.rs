# 7.1.2 — Correct hydraulic table metadata, derivatives, and constructors

## Goal
Add validated caller-declared unit-symbol metadata and mathematically correct piecewise-linear derivatives to generated hydraulic tables, remove constructors that always fail, and preserve table values, domains, endpoint behavior, and selector rejection.

## TODO items

- [x] Extend `HydraulicTables::new` to receive and store caller-declared unit symbols for head, conductivity, and capacity, with water content documented as dimensionless; preserve its generated grid and values.
- [x] Expose the table metadata through read-only accessors and re-export any public type through `hydraulics/mod.rs` and `lib.rs`.
- [x] Add one internal segment-selection/slope calculation that selects the right-hand segment at internal knots and the left-hand segment at the final endpoint.
- [x] Implement table derivatives as per-segment slopes for theta, conductivity, and capacity, after retaining existing evaluation-domain validation.
- [x] Remove `HydraulicTables::from_selector` and `HydraulicTables::empty`; preserve unsupported-selector errors at `HydraulicModelSelector::from_i32`.
- [x] Update `hydraulic_tables.rs` constructor calls and add checks that metadata labels survive construction and empty labels are rejected.
- [x] Add derivative tests comparing all three outputs with segment arithmetic at nodes and off-knot finite differences away from knots.
- [x] Add deterministic tests for internal-knot right-segment and final-endpoint left-segment behavior, while retaining endpoint acceptance and out-of-domain errors.
- [x] Update selector tests to assert unsupported values fail through `HydraulicModelSelector::from_i32`; run `cargo test -p hydrus-core --test hydraulic_tables`.

## Notes
- Scope is limited to `table.rs`, `hydraulics/mod.rs`, `lib.rs`, `tests/hydraulic_tables.rs`, and this micro-TODO. Do not edit `tests/api_contract.rs`; task 7.1.1 owns it.
- `HydraulicTables` currently generates logarithmic heads and stores `Evaluation` values, with linear interpolation and inclusive endpoints. `derivatives` currently reports capacity as the theta slope and zero for the other two slopes.
- `HydraulicModel` derivative result shape is `HydraulicDerivatives`; `VanGenuchtenModel::derivatives` in `hydraulics/mod.rs` is the contract reference. Unit symbols are metadata only: no conversion or preferred units.
- `HydraulicModelSelector::from_i32` already rejects unsupported selectors. The dedicated table tests currently call the soon-to-be-removed table selector constructor and need to move that assertion to the selector API.
- Preserve current table values, interpolation domain, and endpoint evaluation behavior. Keep table storage immutable externally and all unit-symbol contents private.
