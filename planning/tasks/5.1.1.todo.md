# Task 5.1.1 micro-plan — Define generic boundary-row assembly

## Goal

Add a filesystem-free, typed contract that transforms endpoint tridiagonal rows for generic Dirichlet, signed Neumann/flux, and natural/free cases, with explicit signs and typed validation; preserve physical boundary selection and forcing for Phase 4.

## Steps

1. [x] Reconfirmed the Phase 2 handoff, current `ResetRow` interior-only contract, `HydraulicError` conventions, and the task file boundary before changing code.
2. [x] Defined small public boundary types in new `hydraulics/boundary.rs`: an explicit lower/upper row location, a generic row coefficient/RHS representation, and an enum for only Dirichlet, prescribed signed flux (Neumann), and natural/free transformation requests.
3. [x] Documented the zero-based endpoint convention and the row equation/sign convention (`lower * h[i-1] + diagonal * h[i] + upper * h[i+1] = rhs`), including which coefficient is eliminated at each endpoint and the meaning of the flux sign supplied by the caller.
4. [x] Defined a pure transformation API that accepts the system dimension, endpoint location, source row, and generic boundary request, returns the resulting endpoint row, and does not inspect mesh, forcing, hydraulic state, or mutable solver buffers.
5. [x] Added narrowly named typed `HydraulicError` variants for boundary validation, unsupported variants, and pivot failures, including `Display` text.
6. [x] Implemented shared validation for dimensions, endpoint location, finite values, inactive off-domain neighbor coefficients, and pivot thresholds.
7. [x] Implemented the three generic transformations with documented algebra and unsupported-selector rejection without fallback.
8. [x] Kept `Shift` policy, atmospheric/ponding/seepage switching, root sinks, lower physical modes, `Gauss`/Thomas elimination, retries, and allocation/workspace behavior absent.
9. [x] Registered the private module and exported only the intended boundary types/transformation function from `hydraulics/mod.rs`.
10. [x] Added `tests/boundary_rows.rs` with hand-calculated lower and upper Dirichlet, flux, and natural/free transformations, retaining explicit signs and endpoint/off-diagonal behavior; a `ResetRow` field-for-field conversion verifies the shared row equation.
11. [x] Extended tests for one- and two-node dimensions, invalid endpoint locations, non-finite row/request values, dimension failures, zero/near-zero pivot-relevant values, and unsupported policy rejection through typed variants.
12. [x] Ran only `cargo test -p hydrus-core --test boundary_rows`, `cargo fmt --check`, `cargo clippy -p hydrus-core --all-targets -- -D warnings`, and `git diff --check`; all passed. Report files, exact results, source-algebra limits, and Phase 4 boundary-policy deferrals without editing `STATE_5.md`.

## Notes

- Sources: `WATFLOW.FOR:308-353` shows caller-prepared boundary rows consumed by water elimination; `:359-430` contains physical switching that this generic contract must not encode. `NUMERICAL_DESIGN.md` assigns boundary row construction to the caller and recommends a later reusable Thomas kernel.
- The Phase 2 `assemble_reset_stencil` output is intentionally interior-only (`1..n-1`); this task adds endpoint-row plumbing, not a complete water matrix or a Fortran-parity result.
- The implementation remains `f64`, pure, and filesystem-free. It introduces no numerical dependency, forcing schedule, mesh policy, or physical boundary selection.
