## Notes
- Cause of (b): Rust computes `x_surf - x[i]` (`compat_runner.rs:397`, `:1570`) where `x_surf = x[N-1]` (`deck_reader.rs:996`); Fortran `NodOut` prints `x(i)-xS` (`OUTPUT.FOR:~825`), so the sign is inverted. Pinned reference `model6_exchange\NOD_INF.OUT` prints -0.2500 at both t=0 and t=1; the 21.3.7 note named t=1 only, so I test both. Formatting is in `output_compat.rs:215,317` (f10.4) and probably needs no change; negative-zero handling from 22.1.2 may matter for node 1.
- Nod-in-Fortran `xS=xSurf+Radius`; Radius is nonzero only for centrifuge (cosAlf>1, `deck_reader.rs:362`); to be checked in step 2.
- (c): `make_nod_inf_v_block` prints solver `v`/`vv` for vi/vVi; only the vapor iso/thermal terms are recomputed now. The liquid `vi` (NodOut:~730-756) uses Con, hNew, Grav, density fRE, ConLT term, and at top node the `ThN-ThOldT` and `Sink` terms; the main NOD_INF block also prints `vi+vVi` and `vi/ConSN` from solver `v`. Mapping: bottom node i=1, top i=N, interior averaged. `v_old`/`v_v_old` at t=0 come from `size_exclusion`, whose equivalence to NodOut is unproven.
