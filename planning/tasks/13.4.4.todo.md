## API boundary

`ConvergenceEvidence` receives authenticated caller context: casebook path, current
cache root, explicitly allowed prior cache roots, batch artifact root, exact producer
hash map, escalation policy and optional source-bound reviewed bounds. It independently
checks frozen convergence rows, paths, casebook and producer identities. The caller
owns recipe/activation authentication, bridge gates, batch locks and launch accounting.

- `reference_request(row)` returns exact arguments and cache identity.
- `reference(row, allow_work=False, expected_receipt=None)` returns exact reference
  values and selected-source receipt. Receipt replay pins that source. Prior candidates
  must be complete and admitted; invalid-present entries cannot trigger fallback.
  Current work uses only accepted cache safety semantics, which may reuse authenticated
  completed stages but refuse failed/interrupted repetition.
- `derive(row, run, reference_values, receipt, write=False)` verifies a complete run,
  independently reproduces metrics, authenticates/compares immutable result evidence,
  and returns a classifier record plus independently derived trusted bindings.
- `classify` replays exact ordered row/run/reference/result evidence before invoking
  the pure classifier. `verify_summary` authenticates ordered bindings and reproduced
  classification, retaining historical budget counts as historical.

`write=False` performs verification/replay only, never evidence mutation or reference
work. Bounds require source authentication and root review; the helper does not invent
claims, arithmetic floors, controls or numerical thresholds. Missing bounds remain
missing/inconclusive. Empirical reference uncertainty remains empirical.
