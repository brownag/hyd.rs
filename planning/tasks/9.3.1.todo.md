## Notes
The existing solver accepts a caller-provided node sink slice and integrates it as `timestep * sum(sink[node] * nodal_control_volume_width)`. Accepted state/accounting promotes only after a converged trial; retries restore accepted values. Follow the task's source-derived rules: `Omega = sum(alpha_i * beta_i * dx_i)`; `Compen = OmegaC` when `0 < Omega < OmegaC`, `Omega` when `Omega >= OmegaC`, and zero uptake when `Omega == 0`; node demand is `alpha_i * beta_i * TPot / Compen`. Here beta is root density per length, `TPot` is positive uptake depth/time, and sink is a positive extraction rate. Cap each node at `0.5 * max(theta_trial - theta(h_wilt), 0) / dt`, matching the active `SINK.FOR` logic. Feddes `FAlfa` breakpoints and these equations are source-algebra evidence, not executable parity. The amendment adds optional root input to `WaterStepInput`, workspace-owned trial-sink storage in `water_state.rs`, and existing struct-literal call sites in `allocation_contract.rs`, `atmospheric.rs`, `lower_boundary.rs`, `water_contract.rs`, `water_solver.rs`, and `water_transaction.rs`. Preserve no-root behavior at all of those sites.
