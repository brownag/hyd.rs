## Notes
Current `LowerBoundaryMode` and what each reads from `lower_row` (only `assemble` and `validate`/`prepare` read it):
- `FixedHead{head}`: reads `lower_row` (CallerProvided) in `validate_mesh_and_row` (transform_boundary_row check) and in `assemble`; also reads `lower_boundary_flux` as the exchange flux.
- `PrescribedFlux{flux}`: `lower_row` NOT read in assemble (row built by `lower_flux_row`); `validate` still passes it to `prepare` but it is ignored in this arm. Confirmed unread.
- `FreeDrainage`: same, row ignored (`_ => Ok(())` arm); needs count>=2.
- `Unsupported(..)`: rejected before the row is touched.

Proposed definition:
```rust
pub enum LowerBoundaryMode {
    FixedHead { head: f64, row: BoundaryRow },
    PrescribedFlux { flux: f64 },
    FreeDrainage,
    Unsupported(UnsupportedLowerBoundaryMode),
}
```
(`#[derive(Clone, Copy, Debug, PartialEq)]` still valid if `BoundaryRow` is Copy+Debug+PartialEq; verify in step 2.)

Collapse: `LowerBoundaryPlan{mode}` and `PreparedLowerBoundaryMode` are an exact mirror of the three supported variants. After `prepare` has rejected non-finite/unsupported/bad mesh, the supported subset is just the validated `LowerBoundaryMode`, so `validate` returns/uses it directly. `LowerBoundaryRowStrategy` becomes unnecessary: `prepare_step` returns the row itself (FixedHead -> carried row; flux modes -> `lower_flux_row(..)` with the same inputs). `PreparedLowerBoundary` keeps `condition`, `exchange_flux`, plus `row`. `Unsupported` is unreachable post-prepare; handled with a returning error arm, not `unreachable!`, to keep it panic-free.

Where the lower row is derived: in `assemble` via `input.lower.prepare_step(...)`, replacing the `row_strategy` match at ~water_solver.rs:397-425; the `lower_flux_row` call is moved verbatim into lower_boundary.rs (operand order untouched).
