# 25.7.2 — Standalone Python vapor comparator
## Goal
Stdlib-only CLI `tools/compare_vapor_reference.py` that validates `criteria.json` (vapor-criteria-v1) and compares a `vapor-candidate-v1` file against its fixture (or a `vapor-kernel-candidate-v1` against `kernel_fixtures/vapor_content.json`), computes dry on/off and vapor-nonzero discrimination from reference fixtures, prints a verdict table, and writes a JSON result to a new path (refuses overwrite). Tests in `tools/test_compare_vapor_reference.py`. No Rust, no Rust candidate runs, no planning edits except this file.

## Notes
CLI: `compare_vapor_reference.py trajectory --criteria C --fixture F --candidate X --output OUT.json [--detail]`; `kernel --criteria C --fixture K --candidate X --output OUT.json`; `discrimination --criteria C --fixture-dir D --output OUT.json` (D defaults to reference/vapor_fortran/fixtures, criteria default likewise).
Rows: only FAIL rows listed unless --detail; summary per field (max err, max err/bound, n fail). Result JSON: schema_version `vapor-comparison-result-v1`, mode, criteria_sha256, fixture_sha256, candidate_sha256, case_id, evidence_class per field, rows or per-field summaries (all failures + worst row), unavailable list, verdict.
Math: pass iff err <= bound (inclusive, with exact float compare, no epsilon). Zero floor: bound_t,n = max(abs + rel*|r|, fraction*max|r| over all nodes/times of that field). kernel_capacity_correction field: reference = input-adjusted from fixture, candidate = input-adjusted from candidate. Kernel fields map: vapor_content->kernel_vapor_content, adjusted->kernel_adjusted_hydraulic_capacity.
Discrimination: rule any_print_time_after_initial: per time index>=1, max over nodes |on-off| must exceed factor*tol where tol = max over nodes of (abs+rel*|r_on|) at that node... proposed: per node tol_n = abs+rel*|r_on,n|, pass if any (t>=1,n) has |on-off| > factor*tol_n. Rule max_abs_exceeds_zero_floor_each_case: see Q1. Unknown rule names reject; control/case fixtures must share time_points/nodes.
Evidence class check: field evidence_class must equal pinned-fortran-trajectory in trajectory mode, pinned-fortran-kernel in kernel mode, and equal fixture evidence_class.
