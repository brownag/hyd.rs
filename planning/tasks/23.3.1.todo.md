## Notes
- **Sibling structure copied.** Study rows: `id phase case_id solver precision role axis nodes dt sampling_interval analysis_times timeout_seconds max_steps estimated_output_bytes estimated_work_units status time_controls backend`. Time controls are `fixed` with `dt_min == dt_max == dt`, `increase 1`, `decrease 1`. Diffusion and Robin analysis `[0.25,0.5,1]`, sampling `0.0625`. Example 3 analysis `[50,100,200]`, sampling `1`. Holdouts stay last in the array.
- **Design fields checked.** I recomputed `estimated_output_bytes` with the spec formula for two rows (diffusion space 65 at 2^-7: 2,344,580; Example 3 space 501 at 0.04: 36,987,868). Both match the design. Generator recomputes all 15.
- **Row IDs.** The design IDs carry dt or nodes explicitly (for example `convergence-diffusion_cosine-time_97-dt2e-6-rfc-baseline`). Sibling time IDs use `time_<dt>`, so `time_<dt>` at 97 nodes would collide with the existing `convergence-diffusion_cosine-time_0.015625-rfc-baseline` (257 nodes). I use the design IDs.
- **Checker behaviour now.** `:223` sets rust `modes = ('f64',)`, so the f32 relabel would fail the v1 view. `:338` requires `precision == 'f64'`. `row_signature` skips `precision`, so the v1 row comparison ignores the label. This means the relabel needs a documented exception on `:338` and `:223` only. `test_v2_cases_match_v1` compares only cases, units, contracts and metrics, so it is unaffected. Group rules (single dt per spatial group, single mesh per temporal group, Example 3 space `[251,501,1001]`, `len(rows) == len(v1_rust)`) reject the new rows unless the 15 IDs are excluded. Self-test `launches[-1]` must stay a holdout, so the new rows go before the first holdout.
- **Harness rule.** `parse` (`:151`) accepts a fixed, strict key set. Request keys do not include `policy`, and `solute_benchmark_bridge.py` does not emit it. So the design's `policy == legacy_bridge` test cannot be read in this crate without a key change outside Must-edit. The rule I plan to write is `case_id == example3 && time_end == 200 && sampling_interval == 50 && analysis_times == [50,100,200]`. Only bridge rows carry sampling 50 for Example 3 (verified in step 2 by the generator).
