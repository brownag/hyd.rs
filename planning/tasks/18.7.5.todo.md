- `MassTranInput.epsi` is already the sole weight, so the start call is the same routine with `alf = 1 - epsi`; the new API takes `alf` explicitly so callers cannot pass `epsi` by accident. No change to the driver, adapter, types or `compat/mod.rs` (module already registered; add dead-code allow only if needed).
- STrans reachable-mode behavior must be re-verified in step 1 (several branches assign `=`, others `+=`); ordering test expectations derive from that, not assumption.
- Risk: `Level`/`Iter` types; use plain integers (u32) unless `types.rs` has a convention; will check, not edit `types.rs`.
