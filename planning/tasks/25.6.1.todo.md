# 25.6.1 — Vapor observation view
## Goal
Add a pure, read-only observation view in `V/output.rs` that turns accepted vapor
state plus stored coefficient arrays into typed `NOD_INF_V` rows (node, depth, nine
fields) with the source `NodOut` recomputation, independent of `Veloc`.

## Notes
Approved with coordinator corrections. Source arrays are bottom-first like Rust:
source i=1 is bottom, i=N is surface; NodOut loops i=N..1 and prints N-i+1, so Rust
index i maps to source i+1 and output node = n - i; depth = x[i]-x[n-1] (<=0).
Fields (OUTPUT.FOR:760-816, format 140): Con, ConLT, ConVh, ConVT echoed from stored arrays;
vLiquid, vVapor, vTotal=vLiquid+vVapor, vVapIso=-ConVh_avg*dh/dx, vVapTerm=-ConVT_avg*dT/dx.
Liquid: ConLT echoed but never enters vLiquid (lWTDep=false). Gravity (CosAlf, fRE=1) liquid only.
TOP (Rust n-1) liquid adds -(ThN-ThOld)*dx/2/dt - Sink*dx/2; BOTTOM (Rust 0) has neither;
vapor has no storage at either end. Interior uses same-side (vA*dxA+vB*dxB)/(dxA+dxB), dxA=x[i+1]-x[i],
dxB=x[i]-x[i-1]; solver (water.rs) uses opposite side.
Inputs: heads/temperatures from VaporState::snapshot() (accepted, final); Con/ConLT/ConVh/ConVT,
liquid contents old/new at top, timestep from VaporStepReport (commit 2f6a94c); sink and gravity caller-supplied.
Initial observation: caller passes new==old contents (zero storage by construction). No driver/state edits.
API: `VaporObservationInput`, `VaporObservationRow`, `VaporObservation`, `observe_vapor`, `observe_step`.
