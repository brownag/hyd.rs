## Notes
- **Helper and bounds.** `balance.rs` hardcodes no bounds. `vapor_balance()` (`balance.rs:192`) returns `VaporBalanceReport` with `water.worst_ratio(rel, floor)` and `heat.worst_ratio(rel, floor)` (`balance.rs:~140-155`). `worst` computes `|R| / max(rel*scale, floor)`, so `<= 1` passes. The bounds come only from the test side: `tests/vapor_balance.rs:27-41` `load_bounds()` reads `criteria.json` via `CARGO_MANIFEST_DIR/../../reference/...`, asserts `schema_version == "vapor-criteria-v2"` and `scale == "max_abs_row_term"`.
- **Inputs to the helper.** `VaporBalanceInput` (`balance.rs:37-50`) needs caller-held `coordinates`, `gravity`, `x_conv`, `t_conv`, `sink`, old temperatures, old liquid and vapor velocities, heat materials, material indices and `campbell`. The per-step coefficients come from `VaporStepReport` (`driver.rs:79-119`): `liquid_conductivities`, `liquid_thermal_conductivities`, `vapor_head_conductivities`, `vapor_thermal_conductivities`, `pre_solve_heads`, `pre_solve_liquid_water_contents`, `effective_hydraulic_capacities`, `liquid/vapor_face_fluxes`, `total_face_fluxes`, `liquid/vapor_contents_{old,new}`. So the driver does publish the last-iteration coefficients the helper needs.
- **Boundary records (SELECTOR.IN, "boundary code record" line; field order kTopT, topValue, kBotT, botValue, inferred from `1 45 -1 0.0`):**
  - DF `1 45 -1 0.0`: Dirichlet top, flux bottom
  - DZ `1 45 0 5`: Dirichlet top, zero-gradient bottom (`kBotT=0`, value ignored)
  - FF `-1 0.0 -1 0.0`: flux top, flux bottom
  - FZ `-1 0.0 0 5`: flux top, zero-gradient bottom
  - All four: `lVapor=t`, `lEnBal`-equivalent off, `MaxIt=20`, `TolTh=0.001`, `TolH=1`, `dt=0.1`, `tMax=240`.
- **Config acceptance** (`heat/config.rs`, feat/heat1): top `kTopT==0` is rejected (H3). Vapor accepts only `kTopT>0` or `-1` (`config.rs:11`, `:186`). Bottom `kBotT==0` maps to `ZeroGradient` (`config.rs:174`), so H2 holds. All four forms fall inside the accepted set.
- **Existing test.** `tests/vapor_balance.rs` uses a synthetic 9-node mesh with `k_top_t: 1, k_bot_t: 1` (DD) (`:84-112`) and a seeded RNG. It does not read the case directories.
