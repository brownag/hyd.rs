## Notes
- Bare soil: `CropRes` sets CropHeight=0.1 cm, rc=0, SCF=0 (the initial `rc=60` in SetMeteo is overwritten), so gamma1=gamma.
- `Meteo.out` (unit 43, format 120) exposes DayNo, ETcomb, EvapP, TransP, Rns, Rnl, RadTerm, AeroTerm, Precc, rInterc, ExcesInt, so a parity check is possible.
- Interception, rRoot/rSoil unit conversion (`rConv`, `TTConv`) and the Meteo.in reader are not part of this task (31.3.2/31.3.3); I will return mm/d only.
- Fortran uses `**` on f32 with integer power (`(...)**2`, `**3`) and real power for PAtm (`**5.253`), so use `powi` and `powf` respectively; verify rounding with the hand-computed tests.
- Do not touch `water_solver.rs`, `criteria.json`, `src_reference/`.
