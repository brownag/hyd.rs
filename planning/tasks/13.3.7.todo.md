## Approved Rust arithmetic derivation

This is restricted to the pinned 1001-node, dt=.1, constant-water, linear-equilibrium Example 3. Refuse other cases/configurations. Bind `crates/hydrus-core/src/solute.rs` and `crates/hydrus-core/src/hydraulics/linear.rs` hashes in policy provenance; altered implementations require fresh policy review, not automatic reuse.

Let h=.25, w_min=.125, w_max=.25, S_j=theta+rho*Kd_j, g_j=1/dt+lambda_j, d=theta*D/h=.3096, q=.43. Treat stored binary64 inputs as exact common inputs (decimal-to-binary discrepancies are shared). The exact linear matrix has interior diagonal w*S_j*g_j+q+2d and off-diagonals -(q+d), -d; inlet diagonal w*S_j*g_j+q+d, off-diagonal -d; outlet diagonal w*S_j*g_j+q+d, off-diagonal -(q+d). Reversing native ordering permutes this same system. Row margin m_j>=w_min*S_j*g_j>=.5375; A is an M-matrix with ||A^-1||_inf<=1/m_j. Let a_j=max row absolute sum from those three explicit row shapes. The exact one-step old-state amplification is beta_j=1/(1+dt*lambda_j), and previous-species forcing amplification is eta_j=dt*lambda_(j-1)*S_(j-1)/(S_j*(1+dt*lambda_j)), zero for parent. This sharper propagation follows A*1 >= w*S_j*g_j*1, not repeatedly multiplying a crude inverse bound by w_max/w_min.

Exact concentration envelopes independent of computed output are B_0=1 (constant supersolution with unit inlet), B_1=lambda_0*S_0/(lambda_1*S_1), B_2(t)=t*lambda_1*S_1*B_1/S_2. At t=200 these are approximately 1,.1,2. Initialize all arithmetic errors E_j(0)=0; zero initial state is exact.

Operation audit: Thomas forward elimination uses 5 operations/node (division and two multiply/subtract pairs), backward substitution 3/node and one final division, fewer than 8N total. Per node, bound assembly/storage/intercept work by 96 operations: flux/widths <=24, two local linear mass/derivative/intercept evaluations <=32, source/gamma/diagonal/RHS <=16, remaining copies/boundary arithmetic <=24. Source postsolve stored mass/reaction conversion adds <=24/node; endpoint and scalar setup <=32. Thus 128N+32 safely exceeds every arithmetic operation relevant to one species solve and source transfer (including 8N Thomas). Use u=2^-53 and delta=gamma_(128N+32)=((128N+32)*u)/(1-(128N+32)*u), never an empirical multiplier. Include additive gradual-underflow allowance (operation budget times the smallest positive binary64) and reject nonfinite/unsupported arithmetic.

For Thomas on this strictly dominant M-matrix, pivots remain positive and factors have the M-matrix sign pattern. Exact LU has |L||U|=|A|; rounded multiply/subtract/divide perturbations are covered by gamma counts. Use a conservative 4*delta*a_j matrix backward-error allowance alpha_j, encompassing matrix assembly and LU factors; verify alpha_j<m_j/4. RHS arithmetic uses 8*delta times the sum of absolute expanded terms, so cancellation never uses a relative-error bound on a tiny result. In particular local_mass_terms computes an intercept `theta*C+rho*(Kd*C)-R*C`, mathematically zero but rounded nonzero: both mass terms are explicitly included below. Constants 4 and 8 cover respectively assembly plus rounded LU contributions and the eight expanded RHS/storage/source/intercept contributions, with the operation gamma already covering their arithmetic chains; document these partitions in code and tests.

At each step and species (parents first), set C_old=B_j(t_previous)+E_j(previous) and C_parent=B_(j-1)(t)+E_(j-1)(new), and

    H_j = w_max * [S_j*C_old/dt
                    + lambda_(j-1)*S_(j-1)*C_parent
                    + 2*g_j*S_j*C_old] + q*inlet_j
    E_j(new) = [m_j*(beta_j*E_j(previous)+eta_j*E_(j-1)(new))
                + alpha_j*B_j(t) + 8*delta*H_j + underflow_allowance]
               / (m_j-alpha_j)

The intercept contribution uses the old concentration because the linear solve's initial guess is the copied old state. The extra alpha denominator absorbs dependence of matrix backward error on the computed new solution. Propagating this envelope for all 2000 declared steps is scalar bound arithmetic, not another transport solve or inferred old history. Use outward-rounded bound arithmetic. The two independent orientation implementations each lie within E, so compare profiles with 2E. No observed concentration enters E. Compare equilibrium sorbed with Kd*2E plus multiplication rounding. Both serializers use 17 digits after the decimal in exponential format, sufficient to round-trip binary64; parse round-trip values, recording zero additional serialization uncertainty (and rejecting nonfinite numbers).

For inventory propagate L*S_j*2E plus gamma-counted product/summation error using the same B+E envelopes. For cumulative boundary mass propagate q*dt*sum_steps(2E_j) plus per-step product/addition and cumulative-sum rounding on q*dt*(inlet_j+B_j+E_j). For reaction mass propagate L*dt*sum_steps(lambda_j*S_j*2E_j + lambda_(j-1)*S_(j-1)*2E_(j-1)), plus gamma_(16N+16) per-step mass/rate/width/dt/reduction error on the corresponding positive absolute envelope and gamma_2000 cumulative addition error. These are conservative absolute sums, never relative allowances on cancelling net reaction/balance. Derived balance uses the sum of inventory/boundary/reaction allowances and its final subtraction roundoff. Record every bound and difference in the report.

Synthetic tests will independently check exact coefficients/margins, envelopes and recurrence monotonicity, operation budgets, cancellation/underflow handling, known perturbations inside/outside computed allowances, and zero initial comparison. Bounds are arithmetic identity guards only; they do not establish continuum accuracy or approve scientific solver tolerances.
