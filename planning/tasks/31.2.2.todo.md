# 31.2.2 -- Port radiation Rn, Rns, Rnl

  - `src_reference/TIME.FOR:771-781` (`RadLongNet`).
- Precision & arithmetic constraints:
  - ADR 0010 & ADR 0015: calculations must strictly preserve Fortran single-precision (`f32`) operation order and rounding.
  - Pinned constants: `PI = 3.141592654_f32`, `SC = 118.08_f32`, `SIGMA_COEFF = 0.00000000245_f32`, `TEMP_OFFSET = 273.16_f32`.
- Gotcha: Latitude in input files uses legacy degrees-and-minutes decimal format where 50.30 represents 50 degrees 30 minutes; converted via `(lat - lat.trunc()) * (5.0 / 3.0) + lat.trunc()`.
- Scope boundaries: Files in scope are strictly `crates/hydrus-core/src/meteo/mod.rs`, `crates/hydrus-core/src/meteo/radiation.rs`, `crates/hydrus-core/src/lib.rs`, and planning docs. `water_solver.rs` and `criteria.json` are untouched. No new external dependencies added (ADR 0011).
