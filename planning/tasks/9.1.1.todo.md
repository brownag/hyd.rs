## Notes
- Scoped implementation files are `water_solver.rs`, `water_state.rs`, `atmospheric.rs`, `error.rs`, and `tests/atmospheric.rs`; this micro-plan file is also authorized. Scratch, if needed, belongs under `.development/9.1.1/`.
- A complete, unbounded owned transition `Vec` in the returned report cannot guarantee allocation-free steps with the current `WaterWorkspace::new(node_count)` API: the iteration limit is provided later. A workspace-owned preallocated buffer plus a borrowed report can preserve the complete trace. Capacity must be explicit and validated against the policy before solving.
- The borrowed report means callers must finish reading a step's transition trace before mutably borrowing that workspace for another step. This is the material API tradeoff to review.
- Existing changes already pass atmospheric 9/9 and the orchestrator's workspace, formatting, Clippy, and diff checks; this correction must preserve that behavior. No tolerance or iteration-limit changes are planned.
