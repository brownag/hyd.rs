ATh/Ah/AK/hSat findings: the Rust vapor trial has no Ah/ATh/AK/AThS/AhW scaling anywhere (evaluate_vapor_liquid calls model/table directly; no scaling inputs in VaporWaterContext) => Ah=ATh=1, AT=BT=1 (lWTDep false in selection), Kappa=-1 (iHyst=0), Rate=1. Cap in EpsTh = `properties.effective_hydraulic_capacities` (vapor-adjusted via VaporContent), and ths/thr from `source_materials[m].model.parameters()` (saturated_water_content / residual_water_content). hSat(M): source `FH(model,1.0,par)` (compat `fh`, f32, ~ -1e-9/alfa-scale, tiny negative, via Se clamp 0.999999999999999). Rust has no exposed hSat; options: (a) compute the same f64 formula inline as a private helper in the trial (Se=1-1e-15 clamp); (b) hSat=0. Proposed (a), deviation-free but see Q1. rMax: no source rMax in Rust policy; liquid path has none either => see Q2. TolTh=policy.water_tolerance, TolH=policy.head_tolerance.
