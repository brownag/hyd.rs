## Notes
Files edited: `crates/hydrus-core/Cargo.toml`, `Cargo.lock`, `adapter/fields.rs`, `adapter/transport.rs`, `planning/tasks/19.4.1.todo.md`.

Pre-existing gate (stays untouched): `map_fields` runs `validate_field` on every field before any mapper: object only; keys limited to units|value|availability|reason|provenance; units a non-empty string; value XOR (availability or reason); value must be a finite tree; unavailable needs non-empty string availability AND reason. `field_value` then runs `expect_units`. So mappers only see well-formed wrappers; wrapper keys include `provenance` (ignored).

Wrapper (fields.rs). Wire struct: `{units: String, value: Option<T> (default, deserialize_with = present), availability: Option<String>, reason: Option<String>, provenance: Option<IgnoredAny>}` with `deny_unknown_fields`. `value` present => `Explicit::Available(T)`, else `Unavailable{availability, reason}` (both required, error otherwise; old code `unwrap`-panicked, unreachable after validate_field).
- ADR-0004 explicit null: `Option<T>` would turn `"value": null` into "absent" (=> Unavailable). `present` calls `T::deserialize` directly, so null is only accepted if T accepts null (never for our T). Old: `Available(f(Null))` => error. Same.
- Same `present` is used for every optional DTO field (serde's `Option<T>` default accepts null; old `o.get(n).map(as_*)` rejected null). No field uses a bare `Option<T>` for null handling.
- Integers: old `as_u64/as_i64` reject floats incl. `3.0` (serde_json stores `3.0` as f64). serde `usize/u8/i32` from `Value` also reject floats, negatives for unsigned, and out-of-range. Equivalent (verified by tests with `3.0` and `1.5`). `as_f64`: serde `f64` from `Value` accepts ints and floats as old; non-finite impossible (JSON; `validate_field` finite tree), `DefaultReal::from_input` applied in conversion.
- Strings: `as_string` rejects "" — only `maybe_orientation` reads one; "" is not a variant so still rejected.
- `expect_units`/missing units: unchanged (via `field_value`), so message stays "explicit units required" (does not name the field; test asserts "units").
